# study-mbbs-abroad-landing-page 
Hero Section: Engaging banner with a call-to-action (CTA) to apply now.
Why Study MBBS Abroad: Lists key benefits of studying medicine abroad.
Top Countries Section: Lists countries like Russia, Philippines, and more, where students can study MBBS.
Admission Process: Step-by-step guide for applying to study MBBS abroad.
Lead Form: A form that collects the user’s details (name, email, phone number, country preference).
Technologies Used
HTML5
TailwindCSS for styling
JavaScript for form validation
Google Analytics and Facebook Pixel integration for tracking
Deployment
The project is deployed on [Netlify/Vercel]. You can view the live demo by visiting the link.
Conclusion
This landing page is optimized for fast loading and responsiveness, making it a smooth experience for users on both desktop and mobile devices. The form validation ensures that all fields are filled before submission, and the tracking scripts provide insights into the landing page’s performance.
